15 bundled EV raster assets listed below were generated specifically for this
project. This date records the confirmation, not the date the images were
created. The confirmation was given during preparation for the owner's requested
open-source F-Droid publication.

These project assets are distributed under the repository's existing
**AGPL-3.0-only** license, **to the extent copyright applies**; see
[LICENSE](../LICENSE). This statement applies to the exact file hashes in the
inventory, including those same files in the pinned F-Droid source revision.
Third-party dependencies and the charging dataset retain their separately
documented licenses.

This is a record of the owner's provenance confirmation and the project's
distribution license scope, not an independent legal audit. The generator or
service, model, prompts and original creation dates were not supplied and are
not inferred here.

The 3 Rubina theme, logo and links have been removed from the current application. The shared Carbon wallpaper remains because it is used by other themes.
