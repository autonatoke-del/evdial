# Contributing to EVDial

Issues and pull requests are welcome. Please describe affected Android versions/devices and attach redacted screenshots (remove contact numbers, messages, call logs, location and account names).

- Run the source and JVM tests and Android build/lint before submitting a PR.
- Do not commit secrets, customer data, call recordings, private photo assets, signing keys or production server configuration.
- Do not add non-free or unlicensed source code or artwork. Third-party contributions must include original attribution and license details.
- Contributions to EVDial-authored source should be licensed under GNU AGPLv3, preserving upstream license notices.
- Avoid changing SIM/SIP routing or public update-feed behavior in a visual-only PR.
- Real telephony tests require the device owner's participation; never call real numbers in CI.
